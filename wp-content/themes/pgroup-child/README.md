# PGroup Child Theme

Starter child theme for the PGroup WordPress project.

## Includes
- Basic child theme bootstrap for `hello-elementor`
- Asset enqueue setup
- Custom Post Types:
  - `servico` (Servicos)
  - `projeto` (Projetos)

## Next Steps
1. Install and activate `Hello Elementor` parent theme.
2. Upload this `pgroup-child` folder to `wp-content/themes/`.
3. Activate `PGroup Child` from WordPress admin.
4. Save permalinks once (`Settings -> Permalinks`).
5. Build templates in Elementor Theme Builder:
   - Archive + Single for `Servicos`
   - Archive + Single for `Projetos`
